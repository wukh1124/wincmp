# WinCMP v2.1.11

發布日期：2026-11-25

本版本為 PHP 專案加入內建 Composer 控制台、在儀表板加上更直覺的服務提示，並修正自動更新重啟與多版本 PHP 相容性問題。

## What's Changed

### Added
- **PHP 專案內建 Composer 控制台**：在 PHP 與 Laravel 專案的操作選單中可直接開啟 Composer 面板，自動套用該專案的 PHP 版本執行指令，並提供常用指令提示與執行紀錄查詢。
- **儀表板缺漏與未啟動提醒**：當專案已啟用但缺少 Caddy、缺少所需 PHP 版本，或 Caddy／PHP 尚未啟動時，儀表板上方會依重要程度顯示一則提醒，方便直接下載或一鍵啟動。
- **新增 Python HTTP 專案類型**：專案類型選單加入 `Python HTTP`，自動帶入內建 HTTP 伺服器啟動指令（預設埠口 `8000`），快速架設純 Python 測試環境。

### Changed
- **專案列操作按鈕收整為選單**：將專案列表右側的多顆按鈕整合進操作選單，畫面更簡潔，窄視窗下也不易擁擠或誤觸。
- **啟動與切換分頁時不再閃爍按鈕**：打開軟體恢復先前服務、或在分頁間切換時，服務卡片的按鈕狀態會直接同步顯示，不再短暫閃跳。

### Fixed
- **自動更新重啟更穩定、服務狀態不遺失**：從舊版一鍵更新並自動重啟後，不會再遇到舊程式尚未退出導致埠口被佔用或開不起來的情況，先前開啟中的服務也能正常自動恢復。
- **手動停止服務不再誤報異常日誌**：手動停止 Caddy、資料庫、PHP 或專案執行環境時，終端日誌不會再出現誤判為意外中斷的錯誤訊息。
- **多版本 PHP 與 Composer 執行更相容**：切換不同 PHP 版本執行服務或 Composer 指令時，不會再因共用設定裡的某個擴充模組不存在而失敗；Composer 進度條也會正常在同一行更新，不再洗版。
- **修正儀表板警告重複圖示並調淺底色**：移除警告標題旁重複出現的三角形符號，並將 Sketch 主題的黃色警告底色改得更柔和。
- **依所選 Python 框架實際啟動**：修正未勾選自訂指令時，啟動服務會忽略介面所選框架而改用目錄自動猜測的問題，確保實際執行與預覽指令完全一致。

### Dependencies
- **新增 PHP 8.6.0**：依賴庫管理現在支援一鍵下載與安裝 PHP `8.6.0`。

## Getting Started
1. 下載 `wincmp-v2.1.11-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP.exe` 啟動控制面板。
4. 從 v2.1.10（或更早版本）升級：可直接在軟體內一鍵更新，更新重啟後會維持您原本啟用的服務狀態。
