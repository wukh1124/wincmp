# WinCMP v2.1.5

發布日期：2026-09-22

此版本為 WinCMP 帶來了新的功能、更新與修正。

## What's Changed

### Added
- **終端日誌未讀行數提示**：各分類分頁標籤與運行專案 Hover Tooltip 增強顯示未讀日誌行數（如：`Caddy - 共 4 行 (未讀 2 行)`），點選切換分頁或專案時即時清除標記。
- **版本更新即時檢查與手動刷新**：版本更新頁面新增「檢查更新」按鈕並提供平滑旋轉動畫，進入頁面時若逾 60 秒自動連線取得最新發布資訊，支援穿透快取以避免跳版更新時需升級兩次。

### Changed
- **依賴管理更新互動體驗最佳化**：開啟依賴庫視窗時改採背景靜默自動檢查，手動點擊「檢查更新」保證平滑動畫過渡；移除阻斷式提示彈窗，並在設定實質更新時以平滑淡入淡出切換畫面。

### Fixed
- **Windows 檔案總管路徑與定位異常**：修復在檔案總管中開啟檔案時，因參數逸出包裹引號導致退回「我的文件」目錄的問題；改採原生命令列傳遞，且當目標日誌尚未生成時安全降級開啟所在目錄。
- **版本更新呼吸燈啟動閃爍消除**：啟動新版本時預設保持平靜，待背景檢查確認有新版後才點亮紅點；啟動與更新重啟時自動校驗並清理過期更新標記，徹底解決剛升級完呼吸燈閃現又自動消失的突兀體驗。

## Getting Started
1. 下載 `wincmp-v2.1.5-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.5.exe` 啟動控制面板。
