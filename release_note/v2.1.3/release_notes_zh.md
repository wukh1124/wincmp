# WinCMP v2.1.3

發布日期：2026-09-20

此版本為 WinCMP 帶來了新的功能、更新與修正。

## What's Changed

### Added
- **終端日誌右鍵選單**：日誌區可右鍵複製選取內容、複製此行、全選，並可開啟目前分類的當天日誌檔（系統、Caddy、MariaDB 等對應 `logs/wincmp-*.log`；Node / Custom 對應 `logs/runtime-*.log`）。無法開啟時選項會停用，滑鼠移入可查看檔名與路徑。
- **Runtime 專案日誌選單提示**：Node / Custom 右側專案選單改為自訂下拉，其他專案有新日誌時會顯示圓點提示，便於切換查看。

### Changed
- **資料庫瀏覽器工具列**：MariaDB 與 Redis 的動作按鈕位置對齊；Redis 頁隱藏 HeidiSQL。連線位址與 DB 選單改放在分頁旁，鍵名搜尋移至 Keys 列，減少中間資訊列佔用空間。
- **終端日誌分頁命名**：`Node / Bun` 改為 `Node / Custom`，與實際可選 Runtime 一致。
- **系統設定文案**：「定時自動檢查新版本」改為「自動檢查版本更新(Github)」，並說明啟動時也會檢查、之後預設每 6 小時再查。
- **依賴庫檢查更新**：除連 GitHub 取得建議版本外，會同步重新掃描本機環境，方便反映手動安裝的擴充（例如 PHP Redis）。
- **Redis 鍵值面板**：Keys 與鍵值內容標題列高度固定對齊；複製按鈕縮小，長鍵名與內容顯示更完整。

### Removed
- **Redis 清空當前 DB**：移除危險的 FLUSHDB 操作介面與後端 API。
- **Redis 刪除此鍵**：移除鍵值詳情區的單鍵刪除介面與後端 API。

### Fixed
- **Redis 鍵名搜尋**：輸入未含萬用字元時自動包成 `*關鍵字*`；SCAN 空頁時會繼續翻頁收集，避免誤顯示「未找到匹配的 Key」。
- **Redis 未啟動時重新整理圖示**：連線探測期間不再讓重新整理圖示持續轉動。
- **版本更新提示**：開啟自動檢查後每次啟動會檢查一次，之後預設每 6 小時再查；有新版本時側邊欄「版本更新」顯示呼吸燈圓點，狀態會寫入設定，重啟後不會遺失。

## Getting Started
1. 下載 `wincmp-v2.1.3-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.3.exe` 啟動控制面板。
