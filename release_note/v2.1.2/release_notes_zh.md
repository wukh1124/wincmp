# WinCMP v2.1.2
此版本為 WinCMP 帶來了新的功能、更新與修正。

## What's Changed

### Added
- **內建 Redis 快取瀏覽器**：資料庫瀏覽器新增 Redis 分頁，可切換 DB 0–15、以分頁掃描搜尋鍵名、檢視鍵名／型態／TTL 與內容，並支援單鍵刪除與清空當前資料庫（需二次確認）。Redis 尚未啟動時會顯示引導卡片，可直接前往儀表板啟動服務。
- **PHP Redis 擴充自動啟用**：啟動時自動檢查 `php.ini`，缺少 `extension=redis` 時先備份再安全追加；若擴充被註解，則自動取消註解。儀表板 PHP 卡片新增 Redis 狀態徽章，未啟用時可一鍵修復或前往依賴管理安裝。
- **Redis 自訂連接埠**：設定頁新增 Redis 端口配置（預設 6379），同時用於 Redis 服務啟停與內建快取瀏覽器連線。
- **側邊欄收合簡化**：移除鎖定按鈕與切換頁籤時的自動收合；收合狀態會保存在本機，應用重載後維持原狀。

### Changed
- **儀表板 PHP 卡片版面**：重整 PHP FastCGI 卡片資訊層級，版本、埠口、執行狀態與 Redis 徽章更清楚易讀。
- **依賴管理 Redis 狀態判定**：php_redis 僅在 DLL 已安裝且 `php.ini` 有效啟用時才顯示「已就緒」，降低假陽性誤判。

### Fixed
- **Runtime 啟動指令安全防護**：自訂啟動指令若以 `start` 開頭，或透過 `cmd start`／`Start-Process` 脫鉤執行，將被攔截並提示改用原生前台指令，避免脫離 WinCMP 的進程生命週期管理。
- **Port 釋放保證**：結束佔用埠號的進程後，會同步等待 TCP 端口實際釋放（最多約 3 秒），降低專案重啟時的 `EADDRINUSE` 與前端開發伺服器自動跳號問題；啟動前也會先檢查埠號是否仍被佔用。

### Dependencies
- **Go Redis 用戶端**：後端引入官方 `go-redis/v9`，供內建 Redis 快取瀏覽器使用。

## Getting Started
1. 下載 `wincmp-v2.1.2-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.2.exe` 啟動控制面板。
