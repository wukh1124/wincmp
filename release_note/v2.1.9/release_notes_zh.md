# WinCMP v2.1.9

發布日期：2026-10-23

本版以已修補的 Go 工具鏈重新編譯，因為先前的建置帶有尚未修正的憑證信任弱點。

## What's Changed

### Security
- **改用 Go 1.27.3 編譯**：Windows 執行檔現在由 Go 1.27.3 產出，其 `crypto/x509` 會拒絕含特定不受信任中繼 CA 的憑證鏈（CVE-2026-111943）。v2.1.5 至 v2.1.8 皆以 Go 1.26.2 編譯，沒有這層阻擋，該版本執行過的 HTTPS 下載都會信任那些憑證鏈。
- **工具鏈下限提高**：`go.mod` 現在要求 Go 1.27.3。本機建置會透過 Go 的工具鏈自動切換取得 1.27.3，取不到就直接中止，不會再默默編出帶未修補標準庫的執行檔。

### Dependencies
- **Go 1.27.3 列為最低版本**：README 徽章與環境需求段落同步改為硬性最低 1.27.3。Go 模組相依未變動，`go.sum` 不受影響。

## Getting Started
1. 下載 `wincmp-v2.1.9-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.9.exe` 啟動控制面板。
4. 從 v2.1.8 升級：無需遷移任何設定。更新器會先以 SHA-256 比對 `checksums.txt`，通過後才覆蓋現有執行檔。
