# WinCMP v2.1.8

發布日期：2026-10-22

本版收尾「已被取代的 PHP 執行環境」的生命週期缺口，並讓本機建置入口的行為可預期。

## What's Changed

### Fixed
- **舊版 PHP 清理不再被檔案鎖擋死**：移除已被取代的 PHP 執行環境時，不會再因為 `php-cgi` 仍載入 DLL 而停在 `Access is denied`。程式會先停止受管理的服務、終止該版本目錄下殘留的 `php-cgi`，再重試移除，真的失敗時也會指出仍有幾個行程佔用。
- **升級時立即停掉被取代的版本**：安裝同分支較新的 patch 後，會立刻停止被取代的舊版本並清除其自動啟動紀錄，不會再留下看不到、卻仍在背景服務的執行環境。
- **還原狀態自動校正**：目錄已不存在、或已被較新 patch 取代的 PHP 版本，會從「恢復上次服務狀態」清單中移除，避免下次啟動時又被無故拉起。

### Changed
- **建置入口行為調整**：Taskfile 在 WinCMP 執行中會直接拒絕建置，而不是靜默關閉面板；`clean` 後會確認 `build/bin` 真的已清空；讀取版號不再需要 Git Bash。新增 `task doctor` 檢查 Go、Wails 與 WebView2 版本。

## Getting Started
1. 下載 `wincmp-v2.1.8-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.8.exe` 啟動控制面板。
4. 從 v2.1.7 升級：若升級後仍看到舊 PHP patch 在執行，啟動時會自動停止；清單中的清理項目會在目錄移除後消失。
