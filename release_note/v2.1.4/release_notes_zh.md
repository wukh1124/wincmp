# WinCMP v2.1.4

發布日期：2026-09-21

此版本為 WinCMP 帶來了新的功能、更新與修正。

## What's Changed

### Dependencies
- **PHP 7.4 與 Redis 擴充**：支援 PHP 7.4.33 (NTS x64) 與對應的 PECL Redis 5.3.7 擴充套件，並自動關聯 Laravel 6.x~8.x 專案版本推薦。

### Added
- **在檔案總管中顯示日誌**：終端日誌右鍵選單新增「在檔案總管中顯示」，可直接開啟包含當天日誌檔案的資料夾並選中該檔案。
- **日誌分頁行數統計提示**：終端日誌各分類分頁標籤滑鼠懸停 (Hover) 時顯示服務完整名稱與當前緩衝日誌行數（如：`Caddy - 共 4 行`），標題維持乾淨純文字。
- **依賴管理自動檢查**：進入依賴管理介面時自動於背景靜默檢查更新，並具備冷卻機制避免頻繁重複發送請求。

### Changed
- **資料庫瀏覽器佈局最佳化**：
  - 將 MariaDB 與 Redis 切換器移至頂部主標題列同行置右，懸停於分頁按鈕顯示連線位址與狀態 Tooltip。
  - MariaDB「重新整理」與「Open In HeidiSQL」按鈕分別歸位至資料庫與資料表清單標題列同行置右。
  - Redis 搜尋列移至 Keys 列表頂部，「重新整理」按鈕移至 Keys 標題列同行置右，DB 選擇器移至鍵值內容標題列左側。
  - 統一 MariaDB 與 Redis 左右列表標題列高度為固定 48px，切換分頁介面不再跳動。
- **系統設定輔助說明完善**：精簡設定項開關標題，並為所有開關項目補齊輔助說明文字，版面更一致俐落。

### Fixed
- **全新安裝 Caddy 設定缺失**：修復使用獨立執行檔首次啟動時，未自動釋出內嵌 `snippets/common.caddy` 與 `snippets/php-upstream.caddy` 導致 Caddy 啟動失敗的問題。
- **日誌開啟命令列視窗閃爍**：修復右鍵開啟日誌檔案時跳出命令提示字元黑窗閃爍的問題，並修正特定路徑無法開啟預設編輯器的錯誤。
- **暗色主題右鍵選單文字重疊**：解決 Carbon 暗色主題下日誌右鍵選單與下拉選單背景透明度過高造成的視覺穿透與辨識問題，導入實體選單背景色與陰影。

## Getting Started
1. 下載 `wincmp-v2.1.4-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.4.exe` 啟動控制面板。
