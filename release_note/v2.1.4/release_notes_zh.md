# WinCMP v2.1.4

發布日期：2026-09-22

此版本為 WinCMP 帶來了新的功能、更新與修正。

## What's Changed

### Dependencies
- **PHP 7.4 與 Redis 擴充**：支援 PHP 7.4.33 (NTS x64) 與 PECL Redis 5.3.7 擴充套件，並自動關聯 Laravel 6.x~8.x 專案版本推薦。

### Security
- **軟體更新與依賴下載防禦**：全面實施官方網域白名單、強制 SHA-256 雜湊與 PE 標頭驗證；更新失敗自動回滾舊版，並在下載異常時提供來源連結與手動排查導引。

### Added
- **在檔案總管中顯示日誌**：終端日誌右鍵選單新增「在檔案總管中顯示」，可直接定位當天日誌檔案。
- **日誌分頁行數統計提示**：分頁標籤滑鼠懸停 (Hover) 顯示服務全名與緩衝日誌行數（如：`Caddy - 共 4 行`）。
- **依賴管理自動檢查與手動複製**：進入依賴管理介面時自動背景檢查更新，並新增複製官方下載連結按鈕以利手動排查。

### Changed
- **資料庫瀏覽器佈局最佳化**：重構 MariaDB 與 Redis 切換器、工具列按鈕與搜尋位置，標題列高度統一為 48px 消除切換跳動。
- **系統設定輔助說明完善**：精簡設定開關標題並補齊各項目說明文字，版面更一致俐落。

### Fixed
- **儀表板頁面切換閃爍**：透過狀態快取與骨架屏消除切換頁面時控制按鈕與載入狀態的短暫閃爍。
- **Windows 檔案鎖定與程序警告**：增加依賴目錄重新命名重試機制解決 Windows 偶發存取被拒，並消除停止服務時的偽陽性終止警告。
- **全新安裝 Caddy 設定缺失**：修復獨立執行檔首次啟動未自動釋出內嵌 snippets 導致 Caddy 啟動失敗的問題。
- **日誌與選單顯示問題**：修復開啟日誌時的命令提示字元黑窗閃爍，並解決暗色主題下右鍵選單背景穿透問題。

## Getting Started
1. 下載 `wincmp-v2.1.4-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.4.exe` 啟動控制面板。
