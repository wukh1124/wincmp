# WinCMP v2.1.0
此版本為 WinCMP 帶來了新的功能、更新與修正。

## What's Changed

### Added
- **Redis 伺服器與 PHP Redis 擴充支援**：依賴管理器新增 Redis 服務一鍵安裝與獨立啟停控制（預設 Port 6379）；安裝 PHP 時自動配置 `php_redis` 擴充模組並提示版本相容性。
- **專案拖曳排序與順序持久化**：專案列表支援直覺拖曳自訂顯示排序，限定透過專屬拖曳手柄觸發防止誤觸，排序狀態自動保存至 `wincmp.json`。
- **PHP OPcache 與核心設定自動遷移**：PHP 服務啟動時自動檢測並優化 OPcache 核心配置（含 JIT 與記憶體分配），並自動啟用常用延伸模組（curl, mbstring, openssl, pdo_mysql 等）。
- **依賴下載完成目錄捷徑**：依賴下載完成後保留操作按鈕，並新增「開啟安裝目錄」捷徑，方便直接檢視安裝檔案。
- **本地發布管理與預檢工具**：引入標準化發布規範與自動化前檢腳本，確保發行品質與雙語更新日誌一致性。

### Changed
- **日誌控制台精簡單行風格**：日誌面板頂部工具欄重構為 VS Code 風格單行設計，整合服務分頁切換、清空與日誌級別過濾，大幅提升視覺對比度與操作流暢度。
- **高解析度佈局與字型縮放優化**：專案列表表頭改用 rem 比例縮放，避免高解析度螢幕下欄位折行或錯位；優化服務卡片與依賴管理器的留白間距。
- **後台效能負載優化**：移除未使用的儀表板狀態概覽區塊與無效的 Port 衝突輪詢機制，進一步降低背景閒置時的 CPU 佔用。

### Fixed
- **PHP 設定自動優化觸發時機**：修復 PHP ini 優化配置在初次啟動時未能即時套用的問題，確保每次啟動 PHP 時皆自動校驗。
- **依賴管理器按鈕懸停視覺**：修復依賴下拉選單在特定主題下的 Hover 視覺反饋異常與 Dashboard 下拉箭頭遺失問題。
- **新手引導氣泡模糊問題**：修復引導氣泡在特定背景濾鏡下邊緣模糊的視覺瑕疵。

## Getting Started
1. 下載 `wincmp-v2.1.0-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.0.exe` 啟動控制面板。
