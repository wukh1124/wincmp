# WinCMP v2.1.7

發布日期：2026-10-22

此版本為安全應變版本：內建 PHP 全面更新至修補 CVE-2026-109618 與 CVE-2026-109619 的版本，並新增 PHP 8.5 支援、PHP 生命週期標示與舊版執行環境清理。

## What's Changed

### Security
- **PHP 重大漏洞修補（CVE-2026-109618 / CVE-2026-109619）**：內建 PHP 更新至 8.5.12、8.4.27、8.3.36、8.2.35。這兩個漏洞可讓未授權的遠端請求執行任意程式碼（CVSS v4.0 均為 9.2），官方建議所有使用者立即更新。既有安裝請於依賴庫點「獲取最新」後重新安裝 PHP，或直接下載新版覆蓋。

### Added
- **PHP 8.5 執行環境**：新增 PHP 8.5.12（NTS、VS17 x64）與對應的 php_redis 6.3.0 擴充，可直接於依賴庫下載並自動配置到 `ext/`。
- **PHP 生命週期標示**：服務卡片與依賴庫會標示已停止支援（EOL）與 180 天內即將停止支援的 PHP 分支，滑鼠移入可查看停止支援日期與剩餘天數。PHP 7.3 / 7.4 已無官方 Windows 安全修補，請評估升級。
- **舊版執行環境偵測與清理**：升級 patch 版本後，若 `bin/php/` 仍留有已被取代的舊目錄，介面會列出並提供「清理」按鈕；刪除前顯示完整路徑並需二次確認，且僅針對同分支已被較新版本取代的目錄。

### Changed
- **依賴庫列表精簡**：移除依賴項目標題旁的授權標籤，避免與下拉選單細項及底部聲明重複；授權資訊仍可在選單中查閱。
- **背景作業不再觸發按鈕動效**：依賴庫檢查更新後的回呼改為靜默刷新，只有使用者親自點擊「重新掃描服務」時才顯示載入動畫。

### Dependencies
- **Wails 升級至 2.17.0**：同步更新 go-webview2 至 1.0.23，修正 WebView2 controller 初始化的 COM 參數傳遞錯誤，並讓專案可在 Go 1.27 下建置（舊版 CLI 內嵌的 x/tools 無法解析 Go 1.27 的型別資訊）。
- **預設依賴版本更新**：Caddy 2.11.7、Node.js 24.22.1（上游標記為安全更新）、MariaDB 11.4.13、Mailpit 1.31.6；Composer 2.10.3、HeidiSQL 12.21、Redis 5.0.14.1 已為上游最新。
- **CA 憑證改釘不可變快照**：改用 `cacert-2026-10-20.pem`。原本指向滾動更新的 `cacert.pem`，上游一更新憑證庫就會造成下載校驗失敗。

### Fixed
- **PHP 同分支版本比較修正**：修正版本比較誤用字串排序，導致 `8.4.9` 被判定為比 `8.4.10` 新、可能選到較舊執行檔的問題；現在一律選用最新 patch。
- **php_redis 擴充安裝目標修正**：新增 PHP 分支時，擴充套件不再可能被複製到其他 PHP 版本的 `ext/` 目錄而導致載入失敗。
- **依賴連結歸檔備援**：PHP 官方將舊版移入 `archives/` 後，下載器與依賴檢查會自動改用備援網址，不再直接回報連結失效。

## Getting Started
1. 下載 `wincmp-v2.1.7-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.1.7.exe` 啟動控制面板。
4. 由舊版升級者：開啟「依賴庫管理」→「獲取最新」→ 重新安裝 PHP，即可取得已修補的版本。
