# WinCMP v2.0.6
此版本為 WinCMP 帶來了新的功能、更新與修正。

## What's Changed

### Added
- **連接埠佔用偵測與排除**：啟動專案時若目標 Port 已被佔用，會自動偵測佔用的進程，並提供在 UI 中直接安全終止該進程的選項。
- **自訂啟動指令持久化**：自訂的專案啟動指令現在會保存至 `wincmp.json` 中，避免在取消勾選或重載頁面時遺失設定。

### Changed
- **專案設定介面優化**：調大專案設定面板的標籤字型與說明圖示大小，並修正 Tooltip 氣泡的定位與顯示效果。
- **文案語意優化**：微調自訂指令相關的翻譯文案，使操作提示更為精確易懂。

### Fixed
- **同 Port 專案重複啟動問題**：加入啟動鎖定機制，防止在極短時間內重複點擊啟動相同 Port 的專案而導致的競爭條件問題。

## Getting Started
1. 下載 `wincmp-v2.0.6-win-x64.zip`。
2. 解壓縮至您系統中的任何資料夾。
3. 按兩下 `WinCMP_v2.0.6.exe` 啟動控制面板。
