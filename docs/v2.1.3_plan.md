# v2.1.3 更新內容

1. 資料庫瀏覽器
   1.1 MariaDB / Redis 按鈕位置對齊：重新整理統一在標題列右上，文案一致為「重新整理」
   1.2 Redis 搜尋鍵名：輸入無萬用字元時自動包成 `*query*`；SCAN 空頁時自動翻頁（上限 20 頁 / 2000 keys），避免誤顯示「未找到」
   1.3 移除「清空當前 DB」：UI 與 Go API（RedisFlushDB / redisexplorer.FlushDB）一併移除
   1.4 Redis KEYS 列表與鍵值內容字型：降低等寬字距造成的截斷感，長鍵名可完整換行顯示

2. 下方 Terminal Logs 與 終端日誌 頁
   2.1 Node / Bun 改為 Node / Custom
   2.2 Node / Custom 右方專案選單加上箭號圖標（改為自訂 dropdown）
   2.3 專案選單對「其他專案有新 logs」顯示圓點提示
   2.4 終端日誌支援右鍵選單：複製、複製此行、全選、開啟檔案（啟發式路徑解析，無法辨識時禁用）

3. 依賴庫管理 -> 檢查更新
   - 除連 GitHub 遠端檢查外，同步清除掃描快取並刷新本機環境（例如手動加入的 PHP Redis）

4. 版本更新提示
   4.1 系統設定文案改為「自動檢查版本更新(Github)」
   4.2 開啟自動檢查時：每次啟動必查一次，之後預設每 6 小時檢查；檢查結果持久化，避免重啟後紅點消失
   4.3 已偵測到新版本且尚未更新時，側邊欄「版本更新」右方顯示呼吸燈圓點（沿用既有動畫，修好資料來源）

## 已確認實作決策
- 更新檢查：啟動必查 + 預設 6 小時 + has_update 持久化
- Redis 搜尋：自動補 `*` + 多頁 SCAN
- FlushDB：UI + Go API 一併移除
- 開啟檔案：啟發式路徑解析
