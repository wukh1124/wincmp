# v2.1.7 更新計畫

## 1. 依賴庫管理列表精簡
- **現況**：依賴項目標題顯示授權標籤（例如 `PHP 7.3 NTS [PHP-3.01]`），與選單細項及底部聲明重複。
- **改動**：移除列表標題旁的授權標籤 Badge，僅保留組件名稱與版本（例如 `PHP 7.3 NTS`）。
- **影響範圍**：`frontend/src/components/DependencyManager.tsx`

## 2. 背景任務與按鈕動效規範（UI/UX 規範更新）
- **現況**：依賴庫管理檢查更新時回呼重新掃描，造成主介面「重新掃描服務」按鈕非預期觸發旋轉動畫與「掃描中...」文字。
- **改動**：
  1. 區分按鈕主動觸發與程式背景觸發：僅在使用者親自點擊「重新掃描服務」時展示按鈕載入動效；背景自動觸發時採靜默刷新。
  2. 於 `AGENTS.md` 新增 UI/UX 原則：非使用者直接手動觸發之操作，禁止觸發按鈕動畫或其他視覺動效。
- **影響範圍**：
  - `frontend/src/components/Dashboard.tsx`
  - `AGENTS.md`
