# v2.1.4 更新計畫

## 1. 核心與初始化 (Core / Init)
- [x] **修復全新初始化時 Caddy 設定缺失**：解決下載獨立執行檔首次啟動時，`conf/snippets/common.caddy` 未自動從內嵌資源解壓縮產生的問題。

## 2. 終端日誌 (Terminal Logs)
- [x] **修復日誌檔案開啟問題**：修復右鍵選單「開啟檔案」在特定路徑下無法叫起系統預設編輯器的錯誤。
- [ ] **分頁標籤資訊增強**：
  - 各分類 Tab 支援 Hover 顯示詳細提示（Tooltip）。
  - 各分類 Tab 顯示目前已緩衝的日誌記錄行數（例如：`系統 (120)` 或於 Tooltip 顯示）。

## 3. 依賴套件管理 (Dependency Manager)
- [ ] **自動檢查更新機制**：
  - 進入依賴管理介面時，自動觸發背景靜默「檢查更新」，同步最新遠端依賴配置與本機環境。
  - 加入防抖/冷卻機制，避免重複頻繁發起請求。

## 4. 資料庫瀏覽器 (Database Explorer UI/UX)
- [ ] **頂部佈局緊湊化**：
  - 將 `[MariaDB (MySQL) | Redis (NoSQL)]` 切換器移至頂部主標題列同行置右，縮減縱向空間佔用。
  - 移除顯式 IP 標籤，改為 Hover 於分頁按鈕時以 Tooltip 顯示連線位址與狀態（`127.0.0.1:3306` / `127.0.0.1:6379`）。
- [ ] **MariaDB 面板操作就近歸位**：
  - 「重新整理」按鈕移至 `DATABASES` 清單標題列同行置右。
  - 「Open In HeidiSQL」按鈕移至 `TABLES` 清單標題列同行置右。
- [ ] **Redis 面板佈局最佳化**：
  - 「搜尋鍵名」搜尋列自標題列移至 `KEYS` 列表內容區頂部。
  - 「重新整理」按鈕移至 `KEYS` 標題列同行置右。
  - 「DB 選擇器 (0~15)」移至右側「鍵值內容」標題列左側。
- [ ] **視覺高度對齊**：
  - 統一 MariaDB 與 Redis 左右兩側列表標題列高度為固定 48px (`h-12`)，消除切換分頁時的介面跳動。
