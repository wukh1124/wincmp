# v2.1.5 更新計畫

## 1. 檔案與系統整合 (System & Explorer)
- [x] **修復開啟檔案與目錄退回「文件」問題**：
  - 解決 Go `exec.Command` 傳遞 `/select,` 參數時自動以雙引號包裹，導致 Windows Explorer 解析失敗退回 Documents 的問題。
  - 改以 `SysProcAttr.CmdLine` 傳遞原生參數；若目標檔案缺失則安全降級開啟父目錄，並以 `windows.ShellExecute` 原生叫起。

## 2. 終端日誌 (Terminal Logs)
- [x] **Tab 標題 Hover 顯示未讀行數**：
  - 各分類 Tab 與 Runtime 專案清單 Hover 時，Tooltip 顯示格式增強為 `[服務名稱] - 共 X 行 (未讀 Y 行)`。
  - 無未讀時維持簡潔顯示總行數；點選或聚焦分頁時即時清空該分頁未讀數。
  - 同步補齊前後端 i18n 字典（`未讀 %d 行` / `%d unread`）。

## 3. 依賴套件管理 (Dependency Manager)
- [x] **檢查更新操作體驗優化**：
  - 隔離手動檢查與背景檢查狀態：開啟視窗時自動於背景靜默檢查，按鈕維持靜態不旋轉。
  - 手動點擊「檢查更新」時保證至少 500ms 旋轉過渡，消除瞬間閃爍感。
  - 移除「成功從遠端獲取依賴配置」的阻斷式彈窗提示。
  - 當遠端配置有實質更新時，以平滑透明度淡入淡出（Transition）更新列表，消除畫面突兀跳動。
