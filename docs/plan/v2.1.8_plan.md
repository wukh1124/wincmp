# v2.1.8 更新計畫

主題：**舊版 PHP runtime 的生命週期收尾**。讓「已被取代」的 PHP 版本不再悄悄啟動、卡住或刪不掉，並把建置入口與腳本規範對齊。

## 1. 已完成 (Done)

### 1.1 舊版 PHP runtime（核心）

- [x] **清理不再被檔案鎖擋死**：`RemoveStalePHPPatch` 改為「先停服務 → 終止該目錄下殘留的 `php-cgi` → 以 3 次 / 200ms 重試 `RemoveAll`」；失敗訊息會指出仍有幾個行程佔用，不再只丟 `Access is denied`。
- [x] **新增 `internal/process/procscan.go`**：`FindProcessesInDir` / `TerminateProcessesInDir` / `RemoveAllWithRetry`。以 Toolhelp32 快照 + `QueryFullProcessImageName` 列舉行程，只比對目錄前綴與檔名白名單（避免 `php-8.3.3` 誤中 `php-8.3.33`）。
- [x] **還原狀態校正**：新增 `reconcilePHPRestoreState`，在啟動掃描後、以及安裝完成重掃後執行；移除「已被較新 patch 取代」或「目錄已消失」的 `last_service_state.php` 條目，並停掉其殘留行程。修正「只更新依賴庫，舊版 PHP 卻在背景執行且 UI 沒有卡片」的幽靈行程問題。
- [x] **測試**：`TestRemoveAllWithRetry`（獨佔鎖 → 刪除失敗 → 釋放後成功）、`TestTerminateProcessesInDir`（實際啟動行程、找出並終止）、`TestReconcilePHPRestoreState`（狀態剪枝）。

### 1.2 建置工具與規範

- [x] **`Taskfile.yml`**：
  - 移除 `VERSION` 的 `sh:` 變數依賴（不再要求 Git Bash 在 PATH）。
  - 建置前偵測到 `WinCMP` 正在執行時直接失敗，不再靜默 `Stop-Process -Force`。
  - `clean` 後驗證 `build/bin` 確實消失，避免留下半套狀態。
  - `run-dev` 停止既有實例時輸出提示；`check-frontend` 改用 `npx --no-install`。
  - 新增 `task doctor`（Go / Wails / WebView2 版本檢查）。
- [x] **`AGENTS.md` 腳本規範分層**：檔案型腳本一律 Node.js 且禁止新增 `.ps1` / `.bat`；`Taskfile.yml` 允許內嵌 `powershell -NoProfile -Command`；`bat/**` 定義為 legacy，只維護不擴充。
- [x] **文件同步**：`readme.md` / `readme_zh.md` 的 Wails 需求釘為 v2.17.0、補上 Go 最低版本說明（`go.mod` 宣告值）、加入 `task doctor`、`release.bat` 標註 legacy。

### 1.3 文件整理

- [x] 移除重複的 `docs/v2.1.7_plan.md`（舊版兩條目草稿），保留 `docs/plan/v2.1.7_plan.md` 為唯一來源。
