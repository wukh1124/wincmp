# v2.1.11 更新計畫

主題：**版本更新平滑交接、服務狀態記憶防禦與舊版升級相容**。解決自動更新重啟時「舊進程尚未釋放子服務 Port」、「固定檔名 `WinCMP.exe` 單實例鎖互卡」及「設定檔競爭／覆寫導致記憶服務無法自動恢復」問題。

---

## 1. 背景與範圍說明

`v2.1.10` 已將落地執行檔固定為 `WinCMP.exe`（見 commit `0e51bfc`）。使用者從 `v2.1.9` / `v2.1.10` 自動更新至 `v2.1.11` 時，執行更新交接的前半段仍是舊版程式，因此 `v2.1.11` 需同時包含：

1. **啟動端防禦（相容舊版 `v2.1.9` / `v2.1.10 -> v2.1.11`）**：新進程在 `--restart` 啟動時主動避開舊版遺留進程與撞 Port。
2. **更新端與設定持久化修正（治本 `v2.1.11 -> v2.1.12+`）**：讓新版作為「舊端」退出時就能乾淨交接，並防止日常 `SaveConfig` 洗掉 `last_service_state`。
