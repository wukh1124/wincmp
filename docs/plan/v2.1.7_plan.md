# v2.1.7 更新計畫

主題：**PHP2Shell（CVE-2026-109618 / CVE-2026-109619）安全應變**。以「讓使用者立刻拿到已修補的 PHP」為主軸，其餘只收同主題、低風險的收尾。

## 1. 已完成 (Done)

### 1.1 依賴 (Dependencies)

- [x] **PHP 安全更新**：`php85` 8.5.12、`php84` 8.4.27、`php83` 8.3.36、`php82` 8.2.35（上游 2026-10-21 發布，修補兩個 CVSS 9.2 的 RCE）；SHA-256 與官方 `sha256sum.txt` 逐項核對。
- [x] **新增 PHP 8.5 支援**：`php85` + `php_redis_85`（PECL redis 6.3.0 NTS VS17）。
- [x] **php_redis 目標版本改由 key 後綴推導**：原本硬編碼白名單缺 `_85`，會把 8.5 的 DLL 灌進所有 PHP 目錄（ABI 不符）。
- [x] **下載來源與備援**：PHP 連結改直連 `downloads.php.net`（跳過 302）；`releases/` 遇 404 的 archives 備援改以 `php.net` 網域判斷，避免直連後失去備援。
- [x] **其他依賴**：Caddy 2.11.7、Node 24.22.1（上游標記 security）、MariaDB 11.4.13、Mailpit 1.31.6。
- [x] **cacert 改釘不可變快照**：`cacert-2026-10-20.pem`（原本指向滾動檔，上游一更新就校驗失敗）。

### 1.2 版本正確性與風險提示 (Accuracy & Visibility)

- [x] **版本比較修正**：`scanner` 改數值分段比較（字串比較會把 `8.4.9` 判成比 `8.4.10` 新），含去重與清單排序，並補回歸測試。
- [x] **PHP 生命週期表**：新增 `internal/phpver`，收錄官方 EOL 日期（7.3 → 2021-12-06、7.4 → 2022-11-28、8.2 → 2026-12-31、8.3 → 2027-12-31、8.4 → 2028-12-31、8.5 → 2029-12-31），隨掃描結果輸出。
- [x] **EOL 徽章**：服務卡片與依賴庫對已停止支援顯示 `EOL`，180 天內顯示「即將停止支援」，tooltip 帶停止支援日與剩餘天數。
- [x] **舊版執行環境清理**：`SkippedPHP` 首次曝露到 UI；同分支有較新 patch 時顯示「偵測到已被取代的舊版」與「清理 vX.Y.Z」按鈕。後端 `RemoveStalePHPPatch` 只允許刪除白名單（`SkippedPHP`）內的版本，含格式驗證與 `bin/php` 邊界檢查，並以 `customConfirm` 二次確認。
